Odoo AI Chat – Overview

Odoo AI Chat is a smart assistant integrated directly inside Odoo Discuss. It allows users to ask questions and get instant AI-powered responses without leaving Odoo.

You can switch between Odoo AI and Google Gemini AI easily from the settings. This module automatically replies to user messages in chat channels using Artificial Intelligence, making your Odoo system more interactive, helpful, and intelligent.

How It Works (Simple Explanation)

  • A user sends a message in the Odoo AI chat channel or mentions Odoo AI in any chat.
  • The system detects the message automatically.
  • Based on your configuration:
    • It sends the question to Odoo AI, or
    • It sends the question to Google Gemini AI.
  • The AI generates a response.
  • The response is posted back into the chat instantly by the Odoo AI user.
  • All of this happens automatically in the background without any manual action.

Usage – How to Use It

  1. Install the Odoo AI Chat module.
  2. Go to Settings → AI Configuration.
  3. Select:
    • Odoo AI or Gemini AI
  4. If using Gemini:
    • Enter your Gemini API Key
    • Select the Gemini Model
  5. Save the settings.
  6. Open the Odoo AI chat channel in Discuss.
  7. Start typing your question.
  8. The AI will reply automatically.
  9. You can also mention Odoo AI in private chats to trigger the bot.

Key Benefits

  • Fully integrated inside Odoo Discuss
  • Real-time AI responses
  • Supports both Odoo AI and Google Gemini AI
  • No external website needed
  • Easy configuration from Odoo settings
  • Improves productivity and user support
  • Works for all users with access to the channel

Complete Flow Steps (Behind the Scenes)

  1. User sends a message in chat.
  2. Odoo triggers _notify_thread.
  3. The system checks:
    • Who sent the message
    • Which channel it belongs to
  4. It reads the selected AI Type from settings.
  5. If AI Type is:
    • Odoo AI → Sends request to Odoo AI API
    • Gemini AI → Sends request to Gemini API
  6. AI generates the response.
  7. Response is posted back as Odoo AI user.
  8. User receives the answer instantly.

🔐 Security & Control

  • API keys are stored securely in System Parameters
  • Only selected AI service is used
  • Admin can change AI model anytime
  • No manual intervention required
